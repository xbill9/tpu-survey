215: Scope of #3653: symmetric int4, `group` or `channel` strategy, `pack-quantized`, no activation
216: quantization — the format of every Google QAT release. Asymmetric, 8-bit, `actorder=group` and other
217: formats still raise. Weights are unpacked on the host, so HBM holds half a byte per weight.
218: 
219: **The kernel path is the whole speed story.** `sharded_quantized_matmul` picks its implementation from
220: the *rank of the scale*: a 3D `[in // group, 1, out]` scale routes to the `gmm_v2` Pallas kernel, which
221: dequantizes each tile in VMEM; a 2D scale routes to `xla_quantized_matmul`, which rebuilds the
222: full-precision weight in HBM on every call. Same weights, same numbers (the two agree to 2.4e-3), very
223: different cost:
